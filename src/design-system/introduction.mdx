## Principles

- **Answer first, details on demand.** Every screen starts with a sentence, then numbers, then charts.
- **Alert only when actionable.** A cloudy day is not an alert. A silent microinverter is.
- **One data model, two lenses.** Owners see meaning, installers see mechanics.
- **Units are sacred.** kW for power, kWh for energy, never mixed.
- **One hero element.** The live energy flow on Home. Everything else is calm.
- **Props in, events out.** Components never read the app store, so they render here exactly as in the app.
